For maximum order and to avoid mixing things, I propose to create another branch called Personal which will be pushed exclusively on GitHub, never on GitLab. The idea is that I maintain the branch STAMET_FS25 as a reference to keep track of how the course evolve and put the exercises/projects I have to hand in. For everything else I commit on Personal only.

- To this aim, I shall always pull from the STAMET_FS25 branch only so that it follows side-by-side the course's evolution.
- Then switch to Personal branch and merge the STAMET_FS25 (no conflict shall occurr because there should only be additional files from the prof).
- To upload my exercises I have to switch to STAMET_FS25, manually copying the files I want to make visible, and committing. Alternatively to copying files, I can merge only specific files from the most recent commit of Personal as 
				git restore --source Personal -- Exercise1
which has to be performed in the STAMET_FS25 branch
